* Versions: revised since the conference version
* Conference version (36d156218)

*If* you want decisions to depend on tractable hypotheses (progress, blockers, pattern fit, uncertainty) rather than raw conversation history. *However* if the belief state is just the conversation, the agent cannot cleanly update, compare, or falsify its own assumptions. *Then* represent the belief state as a map of operational hypotheses

#+begin_quote
(=:goal=, =:subgoals=, =:blockers=, =:pattern-fit=, =:expected-next-observation=, =:uncertainty=)

#+end_quote

updated each step using observation and outcomes. *Because* a compact belief state makes predict \(\rightarrow\) observe \(\rightarrow\) update implementable and testable.
