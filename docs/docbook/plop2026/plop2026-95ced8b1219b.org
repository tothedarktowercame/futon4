* Conference version (36d156218)

*If* you want decisions to depend on tractable hypotheses (progress, blockers, pattern fit, uncertainty) rather than raw conversation history. *However* if the belief state is just the conversation, the agent cannot cleanly update, compare, or falsify its own assumptions. *Then* represent the belief state as a map of operational hypotheses

#+begin_quote
(=:goal=, =:subgoals=, =:blockers=, =:pattern-fit=, =:expected-next-observation=, =:uncertainty=)

#+end_quote

updated each step using observation and outcomes. *Because* a compact belief state makes predict \(\rightarrow\) observe \(\rightarrow\) update implementable and testable.

None of the six keys the pattern names (:goal, :subgoals, :blockers, :pattern-fit, :expected-next-observation, :uncertainty) occurs anywhere in futon2 or futon3c source. The belief state that was built is different and arguably better grounded: belief.clj keeps a map from entity id to a posterior distribution over a fixed status set (the M-INC per-entity vocabulary), with an explicit observation model (A matrix), transition model (B matrix), validity checks, and typed omitted observations. The If, However and Because of R1 hold for it; the Then describes a shape that does not exist. The current text is unchanged here, so it carries the same mismatch.
